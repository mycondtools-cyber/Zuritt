# Дифузори, решітки, анемостати, пленуми — каталог і конфігуратор

Каталог вентиляційних дифузорів з онлайн-конфігуратором (розмір, опції, RAL), орієнтовним аеродинамічним розрахунком, кошиком-заявкою та адмін-панеллю.

**Стек:** Next.js 15 (App Router) · React 19 · Tailwind CSS 4 · Prisma 6 · PostgreSQL.

## Що є

**Сайт**
- Каталог 94 виробів у 4 розділах (вкладки): 30 дифузорів, 53 решітки, 6 анемостатів, 5 пленумів і розподільчих боксів; фільтри за категорією / формою / монтажем, пошук.
- Типи конфігуратора: типорозміри з таблиці, довільний Ш×В, щілинний (довжина + щілини), бокс (габарити + патрубки; для AF / FLX габарити рахуються автоматично з отворів), додаткові числові поля (діаметр повітроводу, ширина рамки, товщина склопакета).
- Конфігуратор по кроках: витрата повітря (з калькулятором за площею та кратністю) → розмір (з автоматичною рекомендацією) → виконання → колір RAL (431 колір) → розрахунок і ціна.
- Розрахунок: живий переріз, швидкість на виході, швидкість у робочій зоні, втрата тиску, ΔT у зоні; зелена / жовта / червона оцінка і пояснення простими словами.
- Ціна в грн / €, доплата за нестандартний RAL, термін виготовлення, маркування для замовлення (`PDK (RAL 9016) 400x400`).
- Заявка (кошик) → зберігається в базі, за потреби дублюється в Telegram. Ціни перераховуються на сервері.

**Адмінка** (`/admin`, вхід за паролем)
- **Товари:** назва, фото (завантаження або URL, порядок), режим розміру (таблиця типорозмірів / довільний Ш×В / щілинний), ціни, опції з доплатами (грн або %), підказки, коефіцієнти розрахунку, опис, показ на сайті, дублювання.
- **Ціни:** усі ціни на одній сторінці, зміна на % для фільтра, імпорт з Excel (вставити колонки «Код / Розмір / Ціна»), експорт CSV. Модель: типорозміри — ціна розміру; панелі — фіксована + м² + периметр; щілинні — фіксована + за метр для кожної к-сті щілин; опції — доплата фіксована / % / за розміром / за щілину й метр; RAL — надбавка кольору × коефіцієнт фарбування виробу.
- **Кольори RAL:** стандартні (без доплати), популярні (показуються одразу), додавання своїх.
- **Категорії, налаштування** (курс EUR, доплата за RAL, контакти, Telegram), **заявки** зі статусами.

## Наочність

- **Моделювання потоку повітря** (стиль CFD) у конфігураторі: поле швидкості в перерізі приміщення (палітра Turbo), ізолінія 0,25 м/с — межа комфорту, анімовані траєкторії частинок, перемикач «Швидкість / Температура». Швидкість і ΔT на осі струменя — з тієї ж моделі, що й розрахунок (`jet()` у `src/lib/calc.ts`, тест `tests/flowfield.test.ts`); поле довкола — інженерна модель струменя й зворотного потоку (`src/lib/flowfield.ts`), не повний CFD. Тип схеми — `vizKind` у `src/lib/products.ts`.
- **3D-моделі** (вкладка «3D» у галереї): параметричні, будуються з обраних розмірів (`src/lib/model3d/spec.ts` → `build.ts`, three.js вантажиться лише при відкритті). Матеріал — порошкова фарба в обраному RAL (глянець / мат / металік), розмірні лінії з посадковим розміром, обертання й масштаб. Сімейства: квадратні PDK / PDK+R, круглий NCD, анемостати, решітки з ламелями (одно- й дворядні, лінійні), щілинні SD / SDH / SDT / RSD.
- **Виріб у кольорі RAL**: обраний колір одразу показується на фото в галереї (65 товарів). Маски «тільки виріб» і найкраще фото для перефарбування готує `python3 scripts/recolor/build_masks.py` (→ `data/recolor.json`, `public/products/*/recolor-mask.png`); перевірка — `scripts/recolor/preview.py`. Товари, де результат поганий, виключено списком `REJECT`.

## Мови

Сайт працює українською (адреси без префікса: `/d/pdk`), англійською (`/en/d/pdk`) і польською (`/pl/d/pdk`). Перемикач мови — у шапці; при першому відвідуванні мову підбираємо за налаштуваннями браузера. Адмінка завжди українською.

- **Інтерфейс** — файли `src/messages/uk.json`, `en.json`, `pl.json` (кнопки, підказки, повідомлення).
- **Каталог** — у картці товару в адмінці, розділ «Переклади»: назва, короткий опис, опис, підписи опцій і полів; лічильник показує, скільки перекладено. Порожнє поле — показується українською. Переклади категорій — на сторінці «Категорії».
- **Заявки** зберігають мову клієнта; параметри позицій менеджер бачить українською.
- Стартові переклади всіх 94 товарів — у `data/seed.json`. `npm run db:seed` додає лише відсутні мови; `npm run db:import-translations` перезаписує переклади з файлу.

**Валюти й маржа** (`/admin` → «Налаштування» → «Валюти й маржа»):
- для кожної мовної версії — валюта (гривня / євро / злотий) і коефіцієнт маржі (1,15 = +15 %); типово: українська — грн, англійська — €, польська — zł;
- ціни в адмінці лишаються в гривнях без маржі, клієнт бачить `ціна × маржа ÷ курс`; маржа діє на виріб, опції й фарбування;
- курси EUR і PLN — автоматично з НБУ (bank.gov.ua, оновлення кожні 6 год, кнопка «Оновити зараз»; якщо НБУ недоступний — діє останній курс) або вручну;
- заявка зберігає валюту, курс і маржу, з якими клієнт бачив ціну, — у картці заявки видно і суму клієнта, і суму за прайсом.

**Додати нову мову** (напр. німецьку):
1. `src/i18n/routing.ts` — додати `"de"` у `locales` і назви в `LOCALE_NAMES`, `LOCALE_SHORT`, `INTL_LOCALE`.
2. Скопіювати `src/messages/en.json` у `de.json` і перекласти (тест `tests/i18n.test.ts` перевіряє, що ключі збігаються).
3. Перекласти товари й категорії в адмінці — вкладка нової мови з'явиться автоматично.

## Розрахунок

Формули — `src/lib/calc.ts`, тести — `tests/calc.test.ts`:

- `v0 = Q / (3600·A0)` — швидкість у живому перерізі
- `dP = ζ·ρ·v0² / 2` — втрата тиску
- `vx = K·v0·√A0 / x` — швидкість струменя на відстані x
- `ΔTx = n·ΔT0·√A0 / x`

`A0` береться з таблиці розмірів (якщо заповнено) або як `коефіцієнт × габаритна площа`. Для гіпсових CRL/PCR/SQR і сопел JN живий переріз уже взято з каталогу виробника; для решти стоять типові довідкові коефіцієнти — їх варто уточнити за технічними таблицями виробника в адмінці (розділ «Коефіцієнти розрахунку»).

## Запуск локально

```bash
cp .env.example .env        # вкажіть DATABASE_URL, ADMIN_PASSWORD, AUTH_SECRET
npm install
npm run db:push             # створити таблиці
npm run db:seed             # наповнити каталог разом з прайсом виробника
npm run db:import-prices    # (за потреби) перезаписати ціни в наявній базі прайсом виробника
npm run dev                 # http://localhost:3000, адмінка — /admin
npm test                    # тести розрахунку, звірка з виробником, мови
```

Повторний `db:seed` оновлює лише технічні дані (коефіцієнти, живі перерізи, терміни) і не чіпає ваші ціни, опції, описи й фото. `db:import-prices` свідомо перезаписує ціни, доплати опцій і надбавки RAL.

## Деплой на Vercel

1. Створіть базу Postgres (Vercel Postgres / Neon / Supabase) і скопіюйте connection string.
2. Імпортуйте репозиторій у Vercel, додайте змінні `DATABASE_URL`, `ADMIN_PASSWORD`, `AUTH_SECRET`.
3. Один раз з локальної машини з тим самим `DATABASE_URL`: `npm run db:push && npm run db:seed`.
4. Ціни вже з прайсу виробника — змінюйте їх у `/admin` → «Ціни» (масово на %, імпорт з Excel) або в картці товару.

Фото, завантажені через адмінку, зберігаються в базі (таблиця `Media`), тому окреме сховище файлів не потрібне.

## Фото й логотип

На сайті головний — квадратний логотип (`public/brand/mycond-logo-square.png`, шапка сайту й адмінки); на виробах — горизонтальний (прямокутний).

На фото виробів логотип AEROSTAR замінено офіційним горизонтальним логотипом MYCOND (брендбук 2024, `public/brand/mycond-logo-horizontal.png`) у тому ж місці, з тим самим кутом і розміром (149 фото, `scripts/rebrand/`). Оригінали — у `assets/aerostar-originals/` (сайт їх не віддає). Повторити обробку: `python3 scripts/rebrand/rebrand.py`; зони логотипів нових фото додаються в `scripts/rebrand/jobs.json`.

## Дані

`data/seed.json` і фото в `public/products/` — стартові матеріали виробника (Aerostar) для 30 моделей. Їх можна замінити у будь-який момент через адмінку.
